## 项目介绍

本项目是Data Science Lab的课程项目，本项目的核心思路是，要把抽象概念变成可以量化、比较的指标，这称之为操作化，在操作化完成以后还需要进一步深度分析。本项目从意大利的金融素养问卷出发，首先把金融素养这一抽象概念，从原始问卷数据变成指标，进而比较并一步步分析。

项目的结构为：

```
1. 问题引入
2. 数据
3. 传统金融素养指标构建
4. 数字金融素养指标构建
5. 验证
6. 分析问题
7. 进一步分析
8. 结论
```


## 问题引入

数字金融技术不断发展，人们对数字金融的素养，和对传统金融的素养是否相同？或者说，这两者能否一概而论，能否共用一种指标来表示？或者说，二者相关吗？如果相关，相关到什么程度？如果不相关，究竟哪些人对金融的两个领域表现不同？以及最后这些差异是否对应现实中的数字金融行为和风险经历？

本项目就是基于数据逐步探讨这些问题。

## 数据

数据来自意大利银行(Banca d'Italia)，2023 IACOFI survey。意大利央行从2017年开始每三年开展一次；调查方法并不是意大利央行自己完全独创的，而是基于OECD/INFE制定的统一金融素养调查框架。2023年这一轮第一次系统加入了digital financial skills / digital financial literacy相关问题。我们的数据也就来自于这里。

原始数据是一个大型表格，4862行x219列。大概格式形如：

|             |qd1 |  qd7  | qk3 |  qk4 |  qs1_1| ...| wght|
|----|----|----|----|----|----|----|----|
|Person 1     | ...|   ... |  ...|   ...|    ...|  ...  | ...|
|Person 1     | ...|   ... |  ...|   ...|    ...|  ...  | ...|
|Person 1     | ...|   ... |  ...|   ...|    ...|  ...  | ...|
|....| ...|   ... |  ...|   ...|    ...|  ...  | ...|
|Person 4862| ...|   ... |  ...|   ...|    ...|  ...  | ...|


一行就是一个受访者，一列就是一道问卷题目、人口统计变量或者调查辅助变量。数据中还有 `wght`，即 survey weight，其中`wght`是这个受访者在总体统计中代表多少人口。

调查内容比较丰富，不止包括金融问题，还包括人口学信息、个人经济情况等等；

数据可以在这里获得：
```
https://www.bancaditalia.it/statistiche/tematiche/indagini-famiglie-imprese/alfabetizzazione/index.html
```
而配套了非常重要的data description，也可以一并获取。

## 传统金融素养指标构建

第一步是先把数据变成指标，我们需要根据结果重建指标，因为元数据并没有数字金融素养或传统金融素养的指数。

传统金融素养，我们的构建方法是：

$$traditional Financial Literacy = Knowledge + Behaviour + Altitude$$

或简写成

$$T = K + B + A$$

其中，K∈[0,7],B∈[0,9],A∈[0,4]

所以总共传统金融素养是0到20分。

Knowledge比较简单，就是一些问题，结果只有1或者0，如

```
df["qk4"].eq(0)
```
如果输出1，就是说明 qk4这个问题答对了，否则就答错了，然后7道题相加，就是K的分数。有一道关于复利的问题要求前置问题也是正确的，否则会一同算错误。

接着就是关于Behaviour的问题，这部分稍复杂一些，有些问题答案不是0或1，还可能是2分，因为要看你怎么行为，你平常怎么处理钱来评分，判断标准也复杂一些，如关于`Budget`的一项，需要采访人同时负责管理金钱，并且使用至少两种预算方法，才能记作1分。这一步相当于把一系列具体行为合成一个indicator，而不是直接加分。

第三部分关于Attitude更不一样，是询问态度，回答可能是1到5，我们采用先取平均再减1的办法处理，也就是

$$x = \frac{x_1+x_2+x_3}{3} - 1$$

而每一项都可能是1到5，这样总分数就是0到4。这个数不一定是整数。

最后，把这三项直接加起来：

$$TFL = Knowledge + Behaviour + Altitude$$

总分在0到20之间，由于Attitude的问题，也不一定是整数。

到这一步，我们就完成了操作化，改变把原始的问题数值变成了可以量化的指标。


## 数字金融素养指标构建

这一步我们需要处理数字金融素养的指标。这一步和传统金融素养非常相似。但是内容不同，由于过程重复，且答案基本上只能是0或1，比传统金融素养还要简单，所以就不额外说明了，其结构如：

$$Digital Financial Literacy = K_d + B_d + A_d$$

其中，K_d∈[0,3] B_d∈[0,4]，A_d∈[0,3]，这样DFL总分就是0~10.


调查数据还额外询问了互联网的接入程度，如果没有互联网接入，也不会直接认为数字金融素养等于0，这是两码事，所以不能上网的一小部分人要排除出数据。


## 验证


我们已经构造了两个指标了，还不能立刻用来分析问题，还需要验证一下。官方公布了指标，我们需要根据官方的指标，判断我们指标构建的是否正确。

我们可以给每个人，或者说每条数据都计算出两个素养分数，不过要想衡量总人口的指标，还需要参考原始数据中的一个权重参数，意思是他们代表意大利人口的权重不同，有些人的权重更大，所以我们需要使用加权平均数。

也就是说，我们这一步相当于在重建官方答案的结构。最后成果如下：

| 指标                       |   我们算的 |     官方 |
| ------------------------ | -----: | -----: |
| Traditional knowledge /7 |  3.694 |  3.700 |
| Traditional behaviour /9 |  4.676 |  4.700 |
| Traditional attitude /4  |  2.308 |  2.300 |
| Traditional total /20    | 10.679 | 10.700 |
| Digital knowledge /3     |  1.280 |  1.300 |
| Digital behaviour /4     |  2.086 |  2.100 |
| Digital attitude /3      |  1.236 |  1.200 |
| Digital total /10        |  4.602 |  4.600 |


我们可以看到，这个答案和官方数据几乎完全一样，所以我们基本可以断定，成功复现了官方的scoring scheme。当然，至于官方指标构建的是否足够科学规范，就是另一个问题了。

## 分析问题

数据指标构建完成，可以分析问题了。

我们之前问，传统金融素养和数字金融素养二者是否相关，现在可以直接算一下相关性了，当然需要先同步一下scale。

计算结果是：
```
Spearman correlation: 0.443
p-value: 4.83e-212
```

这就比较有意思，他们不是完全无关，而是具有中等程度的相关，并且p-value小的离谱。如果相关性非常高，那么我们可以说两个指标基本上是重复测量，而如果很低，那么也可以说他们基本无关，但是恰好二者是中等相关，我们怀疑，可能有一些类别的人，在两方面表现差别比较大，到底是哪些人？这就是进一步探究的问题。


首先，我们先把这个传统金融素养与数字金融素养的散点图画出来。我们以70%为及格线，可以把图分成4个区域：

![Traditional and digital financial literacy](/files/DSlab/traditional_and_digital_financial_literacy.png)

这4个区域，也就是四类人，构成了4个profile（请注意是加权后的），各自比例如下。
| Traditional | Digital | Profile          | proportion|
| ----------- | ------- | ---------------- | --- |
| 高           | 高       | Both             |5.84%|
| 高           | 低       | Traditional only |11.70%|
| 低           | 高       | Digital only     |14.37%|
| 低           | 低       | Neither          |68.09%|

就是说在70%的及格线下，有26.07%的人两方面能力不匹配。

其实到目前为止，已经可以回答前面第一个问题了，那就是能否把两个问题合二为一，用一个指标？答案是这样不合理，因为有大约四分之一的人口在这两方面的能力表现并不相同，还是应该分开报告。

## 进一步分析


到底是哪些人在两方面表现不同？元数据中有人口学信息，我们打算按照人口学来分组，我们选择以下几种特征来分组：

* Gender
* Age
* Education
* Region

性别比较简单，就2组；

有些人没有给准确年龄，只给了年龄段就用年龄段中点代替。再分成四组18–34，35–49，50–64，65–79；

教育程度本来有很多组，这里为了方便分析，归纳成三组：Tertiary，Upper secondary，Lower secondary or less；

地区也分组归纳，分成North，Centre，South and Islands，其实因为意大利北富南穷，所以地区分组也约等于收入分组，不过我们这里暂时不做详细讨论，就指讨论地区；

然后，就可以按照分组来各自统计分数，这里我们换成了百分制分数。得到如下的结果：


| 特征        | 群体                      | Traditional | Digital |
| --------- | ----------------------- | ----------: | ------: |
| Gender    | Men                     |       55.51 |   46.95 |
|           | Women                   |       53.49 |   45.08 |
| Age       | 18–34                   |       50.04 |   42.61 |
|           | 35–49                   |       56.69 |   47.64 |
|           | 50–64                   |       55.84 |   46.45 |
|           | 65–79                   |       55.01 |   47.69 |
| Education | Tertiary                |       59.54 |   51.42 |
|           | Upper secondary         |       54.45 |   45.40 |
|           | Lower secondary or less |       48.03 |   40.64 |
| Region    | North                   |       55.96 |   47.56 |
|           | Centre                  |       54.92 |   45.84 |
|           | South and Islands       |       52.26 |   44.02 |

这里很有意思，看表格我们有一些结论：


首先，传统金融素养基本都比数字金融素养高，数字金融的门槛可能始终高一些，这其实符合人们的认知；

其次，性别不会对金融认知有什么影响。不过注意，这些数据都是描述性的，即使存在区别，也不能简单认为就是该因素导致的。

第二是年龄，这个很有趣，我们发现18–34组明显比其他年龄组的人在两方面分数都更低，这个和人们平时的印象不同，尤其是数字金融的分数，并不是年轻人就更懂数字金融，至少在意大利如此；

第三是教育，这个差别最大，受教育程度高的，在两方面都能有更高水平的认知，而反之则更低，这符合人们的印象；

第四是地区，大体上来说，北部、中部、南部依次下降，但是差别并不是非常显著，考虑到北部和南部的收入差距要明显更显著，所以我们也可以说，地区和收入，与金融素养没有很强的关联。

那么既然，年龄和教育与金融素养的关系比较大，我们就进一步分析一下。我们换一下视角，不看某中金融素养中各种人口的比例，我们反过来看某类人口中，各种金融素养的表现。

首先来看人口：

| Age   | Both | Traditional only | Digital only | Neither |
| ----- | ---: | ---------------: | -----------: | ------: |
| 18–34 | 3.34 |            11.43 |        12.73 |   72.50 |
| 35–49 | 6.83 |            13.78 |        14.88 |   64.52 |
| 50–64 | 6.74 |            10.94 |        15.50 |   66.82 |
| 65–79 | 6.26 |             9.49 |        13.89 |   70.36 |


首先，整体表现最好的其实是35–49组，这个组里的Neither最少；而50–64组里面，digital only的比例最高，也就是说这些人反而是最懂数字金融的，甚至只懂数字金融的，比只懂传统金融的还要明显多，其他组也是，只懂数字金融的反而更多一点。

我们前面说，整体上来看，数字金融整体上分数更低一点，为什么这里Digital only的人数都更多呢？其实二者不矛盾，前面说有大概四分之一的人“偏科”，而这些偏科的人里面，大部分是更懂数字金融的。本人提出一个猜想，就是近些年数字金融概念比较火，热度比较高，所以这些本来不懂传统金融的人，专门了解了一下数字金融，造成了这个结果。当然，这至少一个非常初步的猜想，具体如何尚待论证。

教育水平的影响是最显著的，教育水平高的人群，对两种金融的了解都显著高于其他人，三组受教育水平的人的表现成梯次下降。

| Education               | Both | Traditional only | Digital only | Neither |
| ----------------------- | ---: | ---------------: | -----------: | ------: |
| Tertiary                | 9.92 |            16.27 |        17.30 |   56.51 |
| Upper secondary         | 4.98 |            12.03 |        12.60 |   70.39 |
| Lower secondary or less | 2.84 |             4.74 |        15.46 |   76.96 |

有趣的是，在Lower secondary or less教育组中，digital only人数显著高于Traditional only，为什么受教育水平低的人更容易了解数字金融，而不是传统金融？本人认为原因类似，可能他们受到热点与传播的影响，更积极的参与到数字金融中去，这个解释同样需要分析论证。


在我们的原版分析中，还进一步分析了两个小问题，使用的方法和处理都相似，这里直接给出结论：

* 即四种金融素养profile的人，实际使用数字金融服务的程度一样吗？

答案是Digital literacy高的人并不一定明显使用更多数字金融服务

* 金融素养高的人，是不是比较不容易遇到数字金融问题？

答案是，一般人们可能会想想，越懂金融，就会被骗的越少，起其实也不一定，可能金融知识懂得越多，参与金融活动就越多，因此暴露与金融欺诈的风险可能也越多。


## 结论


本项目从原始调查数据出发，完成了操作化，重建了官方指标，然后论证了数字金融素养与传统金融素养的不同，并分析了影响各种素养的人群特征，以及这些特征和两种素养的关联，发现了了一些反常识思维的结论，如年轻人不一定比中年人更懂数字金融，也验证了一些日常的思维，如受教育程度明显与金融素养有相关性等。
