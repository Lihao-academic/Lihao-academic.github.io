# 项目介绍

本项目尝试在S&P 500上实践配对交易，最终虽然没有实现明显盈利，不过找到了市场中性，并分散了风险。

我们知道pairs trading可以分散风险，并且实现套利，那么实际上简单的配对交易策略表现如何，我们选择S&P 500的历史数据进行试验，主要目的是完整实现一次配对交易，作为课程的实践训练。

总的来说，项目路线是这样的：
```
1. 问题说明
2. 数据
3. 选股标准
4. 构造pairs方法
5. 交易信号与交易策略(formation period)
6. 回测模拟(out-of-sample trading period)
7. 评价与结论
```

## 问题说明

配对交易是一种经典的量化金融策略，其核心在于，任意一只股票的增长是无法统计的，此时我们即使计算股票的均值、方差等数据也没有意义，因为本质上单只股票的价格是随机波动的；

$$P_t = P_{t-1} + \epsilon $$

而有些股票则显著存在某种关联，我们可以定义一个数列，或者说多只股票的线性组合，可能存在一个稳定的，可估计的均值如：

$$S(t) = aP_A+bP_B+c$$

其中S可能具有稳定的均值和方差。如果两个序列能构造这样一个序列，我们称之为二者协整（cointegration）。当然在实际使用中，我们可以将他们定义为两只股票的残差，并且可能使用对数来消除scale上的差别。

当构造出这样的序列之后，如果S处在高位，那么由于他具有稳定的均值和方差，S就有向下回落的趋势，而如果S在低位，那就有回升的趋势。也就是说，我们不再关注单只股票的价格，而是关注其组合的spread的走势，这个是可预期的。

如果S处于高位，那么就有向下回落的趋势，也就是说，$P_A$和$P_B$的价差有减小的趋势，也就是说$aP_A$将相对的减少，而$bP_B$会相对的上升。

这样，我们只需要做空A而做多B，就可以实现盈利，而不管A和B的价格具体将如何变化。即使整个市场包括A和B都在下跌，只要S处于高位，我们就知道卖A买B是划算的。只要市场不发生结构性变化，导致二者的相关性消失。

我们的问题是，这样的配对交易策略，能不能跑赢大盘指数？

## 数据

我们使用的数据是老师提供的，Bloomberg价格，总共1355只历史上曾进入过S&P500的股票；周度数据共1509周，时间从1990年到2018年。老师介绍说，数据集是survivorship bias free的，其实严格说，是保留了可以消除幸存者偏差的历史信息。

我们以3年时间（156周）作为formation period，以未来半年（26周）作为trading period，并且滚动测试，每半年就重新选择一次最优的pairs并测试效果。

有的股票可能会退市，怎么处理？在每个 formation period 结束时，我们使用最近一期历史指数权重确定当时的 S&P 500 成分股。只有在该时点指数权重大于零的股票，才有资格进入候选股票池；根据这一准则，每个月被认定为S&P成分股的股票数量在498–506，也就是大约500个。

当然，在每次重新选择股票的时候，我们都需要先检测一下当前总共有的股票，更新一下总股票池，这样即使某些股票下个月就退市了，一般也只会对接下来半年有些影响，这个股票在后续选择的时候也可能不被选上，或者选上了也可能不持仓，而且再过半年又要重新选股，所以整体上讲，不会对策略的表现有太大影响，具体的影响程度当然需要进一步的验证。

具体实现的时候，我们没有直接使用`pandas.read_excel()`，来避免把几百MB的数据一次性全部载入内存。最后解析得到的缓存文件是

| 文件                            | 内容           |
| ----------------------------- | ------------ |
| spx_prices_daily.parquet    | 日度股票价格       |
| spx_prices_weekly.parquet   | 周五收盘价，策略实际使用 |
| spx_prices_monthly.parquet  | 月度价格         |
| spx_weights_monthly.parquet | 历史指数权重       |
| spx_sectors.csv             | 股票行业         |
| spx_names.csv               | 公司名称         |
| spx_index_weekly.parquet    | S&P 500 指数   |

之所以用parquet而不是CSV，是因为更快、更小、更适合处理日期信息

## 选股标准
数据载入以后，我们需要谈论一下选股标准。

具体在选股票的时候，我们有一些预先的条件，这样可以降低计算量，并筛选出明显不好的股票：


条件一：历史完整，要求过去3年，也就是156周中都存在完整价格，这样可以筛去刚上市的股票航、数据缺失严重的股票和中间退市的股票等

条件二：价格至少 5 美元，目的是减少极端百分比和交易成本和卖空困难等问题；

条件三：没有单周超过 50% 的变动，这一点也是避免极端股票，亦或者是数据错误等

条件四：有行业分类，这是对数据完善程度的要求，因为我们寻找相关性，行业分类是很重要的参考目标

使用历史成分股还有个元音，就是我们不能拿今天的数据去讨论昨天的股市，因为能生存到今天的股票都是经过了筛选，而真实的交易过程中，我们并不能知道某个股票明天会不会退市，也就是存在幸存者偏差，正好数据集允许我们消除这个偏差。

## 构造 pairs的方法

股票筛选少了，如何选择，或者说构建pairs？

首先，我们只在相同行业内部寻找协整。为什么要在相同行业内部寻找？因为相同行业内部显然更可能具有关联性和稳定的经济关系，而毫不相关的行业则更可能出现伪协整现象或者虚假相关性

我们假设一个行业内部有n只股票，那么显然两两配对的可能性就有$$n(n−1)/2​$$

对于每一对股票，我们都采用Engle-Granger方法检验二者的协整性，由于Engle-Granger是有方向性的，所以必须检测两次。也就是说，

$$Y = \alpha + \beta X + \epsilon$$

和

$$X = \alpha + \beta Y + \epsilon$$

都需要估计一下，估计之后得到的残差的估计值，这里而这残差就是spread，也就是我们将要构建的平稳序列，所以还需要验证残差序列是否平稳，我们选择p-value更小的方向作为候选配对。如果p-value非常小，我们就说两只股票的残差，也就是spread，具体来说就是

$$spread = \epsilon ​=Y_t - \alpha - \beta ​X_t​$$

如果p-value非常小且spread依然表现出这样的强的协整性的概率就非常小。或者说p-value越小，两只表现出来的协整就越不可能是随机的。我们选取p < 0.05的股票对。

不过需要说明的是，我们实际上使用的是对数价格，也就是：

$$ logP_{Y,t} = \alpha + \beta logP_{X,t} +\epsilon_t $$

不过后面为了方便说明，就不写指数价格了。

下一步，我们需要在之前选出的pairs里面，为他们估计对冲比例，我们已经确认这些股票对存在协整关系了，需要计算他们的系数，也就是

$$Y = \alpha + \beta X + \epsilon$$

中的β。

我们这里只接受0.1 < β < 10的数字，避免出现负向关系或者极端不平衡的持仓比例。


计算完成对冲比例，还要计算协整的半衰期。我们知道，spread处于高位的时候，有向下回落的趋势，反之亦然，但是有的组合明显回落的快，有的组合回落的慢，我们采用半衰期来衡量他们的回落速度，我们使用的估计半衰期的公式为：


$$\Delta S_t​ = \phi(S_{t-1}​ - \mu) +\nu_t$$​


均值回归要求 ϕ < 0, 当 spread 高于均值时，预期变化为负；当 spread 低于均值时，预期变化为正。近似半衰期为：

$$T_{1/2} = \frac{ln2}{-\phi}​$$

我们也只选择1 ≤ T ≤ 26的数据，我们trading period只有26周，回归太慢的要淘汰。

最后，依据p-value，寻找从小到大的20对股票，就可以了。

先把所有的对数排序，先从最小的p-value选，已经选中的股票不能再选，这样依次选择够20对就可以了。

## 交易信号与交易策略(formation period)

既然股票对已经存在协整，也就是说这些spread序列都存在稳定的均值和方差，在forming period就可以利用过去3年156周的数据计算出其均值和方差。

而进入trading period以后，就不能再改动那些系数了。根据均值和方差，我们可以计算当前S(t)与均值偏离了多少个标准差。或者说，可以用一个z-score表示一个spread的偏离程度：

$$z_t = \frac{S_t-\mu_S}{\sigma_S}$$

我们每周都要计算这个数值，来检测当前St的状态。我们的策略是：

* 3 \> \|z-score\| \> 2 时，开仓

也就是在S(t)已经偏离均值有2倍标准差了，我们认为这里面有充足的利润空间，开仓进场。更详细来说，z-socre < -2时，由于：

$$spread = \epsilon ​=Y_t - \alpha - \beta ​X_t​$$

此时Y明显相对X低价，我们应该做多Y，做空X；反之z-socre > 2，则做空Y做多X。

* \|z-score\| \< 0.5 时，正常退出

当价差已经回落到半个标准差以内，就不用在继续持有了，因为此时已经没有利润空间了。

* \|z-score\| \> 3 时，平仓

此时价差一再扩大，这种极端偏离可能意味着协整关系已经不存在的了，需要立即平仓止损，该pair当前周期不再交易

持仓比例也算是交易策略的一部分，由于X变化一个单位，Y要变化β​单位，在交易的时候，需要维持持仓比例，才能符合协整关系，所以直接按照对冲比例来分配持仓权重，如，对于：

$$spread = \epsilon ​= Y_t - \alpha - \beta ​X_t​$$

应该把资金按Y:X = 1:β来分配，那么就可以说，权重为

$$\omega_Y = \frac{1}{1+\beta}, \omega_X = \frac{\beta}{1+\beta}$$

而多个pairs我们采用等权配置，也就是所有的pairs分配相同的金额。而一个pair内部则按照1:β来分配。

## 回测模拟(out-of-sample trading period)

确定好策略，并且在formation period决定好参数以后，就进入trading period，开始交易。或者说，开始执行回测。我们采用滚动向前的回测方法(walk-forward backtesting)。

我们用156周，也就是3年的数据计算参数，然后执行26周，也就是半年。接着把时间向后推进26周，用新的156周数据（其中前130周都是旧数据，后26周是新数据）和新的26周做交易，如此滚动回测。由于总数据是1990-2018年，第一个三年不能再次使用，总共剩下26年，也就是52个半年，也就是说可以向前走动52步，形成52个trading windows。

最后，我们将把所有的trading windows的结果拼接在一起，看效果如何。

在执行回测的时候，有几点需要注意。

关于交易成本，我们直接在有买卖时扣取对应的比例即可。而如果trading period结束了还有持仓，需要强制平仓，并且需要支付额外的强制平仓成本。

收益只能使用上一期（上一周）的仓位，因为我们只能是在一周结束之后才能继续决定下一周的策略。

计算收益的时候，需要直接除以20（总pairs的对数），而不能因为有些pairs没有活跃或者持仓，就不计入。因为不持仓，对应的资金我们认为是以现金的方式留在手里的，相当于对应的收益率为0，这本身就应该记作策略的一部分。



## 评价与结论


在金融实践中，一个策略好不好，不能直接比较累计收益，而应该多方面的比较，至少还要包括sharpe ratio和最大回撤。我们选用的指标如下图所示：


| 指标      | 配对策略净收益 | 配对策略毛收益 | S&P 500 |
| ------- | ------: | ------: | ------: |
| 累计收益    |  -2.75% |   6.43% | 498.62% |
| CAGR    |  -0.11% |   0.24% |   7.12% |
| 年化波动率   |   1.75% |   1.74% |  16.41% |
| Sharpe  |   -0.05 |    0.15 |    0.50 |
| 最大回撤    |  -7.84% |  -7.02% | -56.24% |
| 与市场相关性  |    0.08 |    0.08 |       — |
| 市场 beta |    0.01 |    0.01 |       — |

我们有如下结论：

* 市场暴露确实很低，相关性约为 0.08，beta 约为 0.01，这说明我们的策略基本上隔绝了市场暴露，即使2008年金融危机，当年S&P500大盘收益率约-41%，而我们的配对策略依然有+1.6%，说明至少确实可以实现风险分散。好消息是没有跟着大盘下跌，但是坏消息是大盘收益498.62%也完全没有吃到。

* 扣除成本前有微弱的优势，不过远远不如大盘指数，且只需要10bps的交易成本就可以使交易策略失去盈利，完全无法覆盖成本

|     成本 |   CAGR | Sharpe |
| -----: | -----: | -----: |
|  0 bps |  0.24% |   0.15 |
| 10 bps | -0.11% |  -0.05 |
| 20 bps | -0.45% |  -0.25 |
| 40 bps | -1.14% |  -0.63 |

如果我们来看策略收益和大盘指数的收益的相关性，他们的相关性应该接近零，所以应该在0上下波动，而如下图所示，的确如此。

虽然没能实现明显收益，不过其实也是意料之内，因为直到1990年，简单配对交易已经几乎不能再获得显著收益了，而本项目只是一个课程实践，目的是成功跑通一次算法，而我们已经找到了市场中性，完成了风险分散（尽管这个分散可能来自持有资金）
